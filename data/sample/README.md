# Sample data

De bestanden in deze map zijn **synthetische fixtures** om de code en tests reproduceerbaar te kunnen draaien. Ze mogen niet worden gebruikt om winstgevendheid te claimen.

- `prices.csv`: dagelijkse OHLCV-data met één financieel sterk voorbeeldbedrijf (`AAA`) en één zwakker bedrijf (`BBB`).
- `fundamentals.csv`: point-in-time fundamentals die vóór de prijsdaling beschikbaar zijn.

Voor echte backtests moet dezelfde schema-structuur worden gevuld met historische marktdata en point-in-time fundamentals. Zie `../README.md` voor de eisen en openbare bronvoorbeelden.
